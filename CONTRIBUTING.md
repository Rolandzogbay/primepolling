# Contributing

Thanks for wanting to contribute! A few guidelines to keep the project healthy:

- Open issues for bugs or feature requests and include a clear description and reproduction steps.
- Create small, focused PRs with a descriptive title and testing steps.
- Run `npm run lint` and `npm run format` before committing.
- The repository has CI to run lint and build; ensure your PRs pass CI.

If you'd like help setting up CI or deployment, open an issue and tag it `help wanted`.
